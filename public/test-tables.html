ℹ️ Informações Importantes

🔐 Sistema de Segurança: O sistema implementa controle de acesso baseado em login.

🛡️ Permissões por Tipo de Usuário:

  • 🌍 Todos: Ver mesas por ID
  • 👤 User Logado: Criar/editar/apagar próprias mesas + permissões públicas
  • 🛡️ Admin: Acesso total a todas as mesas + operações administrativas

⚠️ Restrições de Segurança:

  • ✅ Criador travado: Mesas são vinculadas ao usuário logado
  • ✅ Operações restritas: Apenas próprias mesas ou admin
  • ✅ Headers de autenticação: Sistema compatível com test-users
  • 🛡️ Edição de criador: Apenas administradores podem alterar o criador de uma mesa

📱 Sessão Persistente: O login é compartilhado entre todas as test-pages.

🖼️ Sistema de Capa de Mesa:

  • ✅ Upload direto: Substitui o campo URL por upload de arquivo
  • 🔄 Preview instantâneo: Visualização antes do envio
  • 📱 Formatos aceitos: JPEG, PNG, GIF (máx. 5MB)
  • 🖼️ Redimensionamento automático: Imagens são redimensionadas para 800x600px
  • 🗂️ Organização: Imagens salvas como "table_[user_id]_[timestamp]"

Estrutura de uma Mesa:

{
    "id": 1,
    "nome": "A Taverna do Dragão Dourado",
    "sistema": "D&D 5e",
    "qntd_jogadores": 4,
    "mesa_aberta": 1,
    "capa": "/uploads/table_1_1749169028.jpg",
    "criador_id": 1,
    "descricao": "Uma aventura épica na famosa Taverna do Dragão Dourado!"
}

Campos obrigatórios: nome, sistema, qntd_jogadores, criador_id

Campos opcionais: mesa_aberta (0 ou 1), capa (imagem via upload), descricao (texto livre)
