ℹ️ Informações Importantes

Erro "UNIQUE constraint failed": Este é um comportamento esperado quando você tenta criar um usuário com email ou username que já existe no banco de dados.

Para resetar o banco: Pare o servidor, delete o arquivo database.sqlite e reinicie o servidor.

Usuários de exemplo já criados: gandalf, strider, elfprince, shieldmaiden

Login: Aceita tanto email quanto username (ex: gandalf ou gandalf@middleearth.com)

  • ✅ Apagar TODOS os usuários (com dupla confirmação)
