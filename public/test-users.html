ℹ️ Informações Importantes

🔐 Sistema de Segurança: O sistema implementa controle de acesso baseado em login.

🛡️ Permissões por Tipo de Usuário:

  • 🌍 Todos: Ver perfis públicos, buscar usuários
  • 👤 User: Editar/apagar próprios dados + permissões públicas
  • 🛡️ Admin: Acesso total + operações administrativas

⚠️ Restrições de Segurança:

  • ✅ Controle de acesso baseado em roles (user/admin)
  • ✅ Primeiro usuário = Admin automático
  • ✅ Perfis públicos para interação social (sem dados sensíveis)
  • ✅ Dados sensíveis protegidos (email, data nascimento)
  • ✅ Edição/exclusão restrita ao próprio perfil ou admin

📱 Sessão Persistente: O login é compartilhado entre todas as test-pages.

Informações Específicas de Usuários:

  • Erro "UNIQUE constraint failed": Comportamento esperado para email/username duplicados
  • 🛡️ Usuário Admin: Clique em "Criar Admin" para credenciais: admin/admin
  • 🔄 Reset de ID: "Apagar Todos" reseta autoincrement - próximo usuário terá ID = 1
  • Login: Aceita email ou username (ex: admin ou admin@diceordie.com)
  • Usuários exemplo: gandalf, strider, elfprince, shieldmaiden

📸 Sistema de Foto de Perfil:

  • ✅ Upload direto: Substitui o campo URL por upload de arquivo
  • 🔄 Troca automática: Foto anterior é deletada ao enviar nova
  • 🖼️ Preview instantâneo: Visualização antes do envio
  • 📱 Formatos aceitos: JPEG, PNG, GIF (máx. 5MB)

Dados Públicos vs Privados:

  • 🌍 Públicos: Nome, username, gênero, experiência, role, foto
  • 🔒 Privados: Email, data nascimento (apenas próprio perfil)
